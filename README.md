Titanic Survival Prediction
A simple machine learning project that predicts passenger survival on the Titanic using Logistic Regression.
Features


Loads Titanic dataset from an online source
Cleans missing data
Encodes categorical features
Splits data into train/test sets
Trains a Logistic Regression model
Prints accuracy and classification report

Requirements :-
pandas
numpy
seaborn
matplotlib
scikit-learn

Run the Project
python titanic_logistic_regression.py

Output
Model accuracy
Precision, recall, and F1-score
